# Get started with Mozart

Welcome! This little project is here so you can try Mozart's loop
without leaving the app : ask the agent, watch it edit files, review
the diff.

## Try one of these prompts

1. `Add a function 'greet(name)' to hello.js that returns "Hello,
   {name}!".`
2. `Wrap the greet() call in a loop that greets three names from an
   array, and print the results.`
3. `Add a small test file 'hello.test.js' with one assertion against
   greet().`

After each prompt, open the **Files** tab on the right to see the
diff. When you're happy, click **Commit** to land the change.

## What you have

- `hello.js` — a single-file starter you can mutate freely.
- A git repo with a `main` branch ready for Mozart to spin
  workspaces off.

You can delete this project from the sidebar context menu when you're
done — or keep tinkering. There's no hidden state.
