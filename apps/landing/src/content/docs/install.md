Mozart is a desktop app. You install it once, point it at a Project, and start running Tasks.

## System requirements

- macOS 13+, Windows 11, or a recent Linux distribution
- Git available on your PATH
- A Claude account (Mozart wraps Claude Code today)

## Download

Public downloads are not yet available. Mozart is in private preview — [request access](https://mozart.build) and we will share a build.

## Verify the install

After launching Mozart for the first time, open the **About** menu. You should see the version number that matches the build you downloaded.
