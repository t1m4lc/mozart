# Mozart

> **Conduct your AI coding agents.** — [mozart.build](https://mozart.build/)

Mozart is a local-first desktop app for running AI coding agents on your own
files. Agents (Claude Code and Codex today) work in isolated workspaces, and you
review every change as a diff before accepting it. It runs on your machine with
your own agent credentials — nothing leaves your device unless you push. Free
forever for individuals.
