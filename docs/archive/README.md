# Archive — historical references only

Everything under this folder is preserved for historical context.

- It is **NOT** a source of truth.
- Specs, plans, audits, prompts, and test scenarios here describe
  earlier versions of Mozart (v0.0.1-era plans and audits, phase
  prompts that have shipped, UI polish plans that were superseded,
  legacy phase-N test scenarios).
- Do not cite, follow, or copy from these files when planning or
  implementing current work.
- Use them only to answer "why did we do X back then?" questions.

## Layout

- `audits/`      — v0.0.1 pre/post-MVP audits
- `plans/`       — superseded plans (v0.0.1, existing-UI-polish)
- `specs/`       — completed specs (formerly `specs/done/`)
- `conventions/` — completed-phase conventions (Phase 7 refactor)
- `prompts/`     — completed phase prompts (Phase 7)
- `test/`        — legacy phase test scenarios (formerly `test/legacy/`)
