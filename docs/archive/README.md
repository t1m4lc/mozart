# Archive — historical references only

Everything under this folder is preserved for historical context.

- It is **NOT** a source of truth.
- Specs, plans, audits, prompts, and test scenarios here describe earlier versions of Mozart, completed phases, temporary investigations, or superseded implementation plans.
- Do not cite, follow, or copy from these files when planning or implementing current work.
- Use them only to answer "why did we do X back then?" questions.

## Layout

- `audits/` — v0.0.1 pre/post-MVP audits.
- `plans/` — old pre-refactor plans kept from the previous archive layout.
- `planning/` — superseded execution plans and TODOs archived during the 2026-06-04 docs refactor.
- `specs/` — completed or superseded specs and phase decisions.
- `architecture/` — shipped design summaries and completed architecture audits.
- `landing/` — historical landing implementation notes superseded by `docs/engineering/release/`.
- `working-notes/` — temporary audits and investigation notes from `docs/tmp/`.
- `conventions/` — completed-phase conventions.
- `prompts/` — completed or superseded implementation prompts.
- `test/` — legacy phase test scenarios.
