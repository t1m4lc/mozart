Create a modern landing page mockup for a developer tool called Conductor.

Conductor is a desktop app that lets developers run multiple AI coding agents in parallel on their Mac. The product helps users create isolated coding workspaces, launch Codex and Claude Code agents, monitor what each agent is doing, review changes, and merge pull requests.

The landing page should feel premium, technical, clean, and startup-like. It should target software engineers, founders, and AI-native product teams.

Visual style:
- Dark background, almost black.
- Subtle gradients and glows.
- High contrast typography.
- Developer-focused aesthetic.
- Clean SaaS landing page structure.
- Large product screenshot as the hero visual.
- Rounded cards, soft borders, subtle shadows.
- Accent colors: white text, muted gray text, green highlights, blue/purple glow accents.
- The page should feel like Linear, Vercel, Cursor, and Raycast mixed with an AI coding product.

Page structure:

1. Top navigation bar

Create a thin top navigation bar with a dark transparent background.

Left side:
- Conductor logo.
- Small announcement pill above or near the nav:
  “Introducing Conductor Cloud →”

Center or right navigation links:
- Changelog
- Docs
- Enterprise
- Join Us

Far right:
- Primary button: “Download”
- Small keyboard shortcut hint: “D”

The navigation should be minimal and developer-oriented.

2. Hero section

Main headline:

“Run a team of coding agents on your Mac.”

The headline should be very large, centered, and bold.

Subheadline:

“Create parallel Codex + Claude Code agents in isolated workspaces. See at a glance what they’re working on, then review and merge their changes.”

Below the subheadline, add two CTA buttons:
- Primary button: “Download Conductor”
- Secondary button: “Learn how it works”

Above or near the headline, add a small update pill:

“See what’s new in 0.52.0”

The hero section should immediately communicate:
- Multiple coding agents.
- Parallel execution.
- Isolated workspaces.
- Git / PR review.
- Local Mac app.

3. Hero product screenshot

Below the hero copy, show a large desktop app screenshot mockup.

The screenshot should show:
- Dark IDE-like interface.
- Left sidebar with repositories and workspaces.
- Center AI conversation / agent task panel.
- Right panel with changed files and terminal.
- Multiple AI coding agents running in parallel.
- Git status, PR status, diff counters, and terminal output.

The product screenshot should be inside a beautiful rounded container with:
- Thin border.
- Soft glow.
- Subtle reflection or shadow.
- Slight perspective or depth effect.

This screenshot is the main visual anchor of the landing page.

Overall direction:
The page should sell a serious developer productivity tool for the AI coding era. It should not feel generic or corporate. It should feel like a high-end tool made by developers for developers: fast, local-first, Git-aware, agent-native, and focused on parallel AI coding workflows.
