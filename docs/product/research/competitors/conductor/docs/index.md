# Introduction



Conductor simplifies running Claude Code, Codex, and other agents in parallel.

Agents are run in isolated workspaces, so they don't step on each other's work or create conflicts.

When you're done making changes, Conductor handles merging & PRs.

Get Conductor running on your Mac.
