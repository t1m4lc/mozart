**Conductor Improvement & Feature Requests**
based on a video take 24 nov. 2025

* **Cloud sandbox execution**
  Add a sandboxed cloud environment where agents can run commands safely instead of executing directly on the user’s local machine.

* **Safer agent isolation**
  Reduce the risk of “YOLO mode” by isolating file changes, terminal commands, and destructive operations away from the main local environment.

* **More model providers**
  Expand model selection beyond Claude and Codex to give users more flexibility depending on cost, speed, and quality needs.

* **Gemini support**
  Add Google Gemini as a selectable model provider, especially since it is becoming more competitive for coding workflows.

* **Open-source model support**
  Allow users to run or connect open-source models for more control, privacy, and cost flexibility.

* **OpenRouter integration**
  Support OpenRouter so users can access many different models from one provider interface.

* **More automation workflows**
  Add more built-in automations for repetitive tasks, especially actions that are currently easier to do manually in the terminal.

* **Less click-heavy interface**
  Improve the UI so users do not need to click around too much when managing agents, PRs, fixes, and workspace actions.

* **Keyboard-first / terminal-like controls**
  Add more shortcuts, command palette actions, or terminal-style controls for power users who prefer fast keyboard-driven workflows.
