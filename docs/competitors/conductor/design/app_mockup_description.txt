Create a dark-mode desktop UI mockup for a coding-agent workspace app, similar to an IDE combined with an AI chat client.

The product is used by developers to manage multiple AI coding workspaces in parallel. The UI should feel compact, technical, polished, and productivity-focused.

Overall layout:
- Full-screen desktop app window.
- Three-column layout.
- Left sidebar for repositories and workspaces.
- Center panel for AI conversation and task execution.
- Right panel split into code changes / PR review on top and terminal on bottom.
- Dark theme with subtle borders, muted gray backgrounds, green success states, red deletion counters, and purple/dark error highlights.
- Use small typography, dense spacing, and IDE-like visual hierarchy.

7. Interaction details to visually imply

The mockup should make these actions obvious:
- Click workspace rows to switch workspaces.
- Click “+ New workspace” to create a new isolated AI workspace.
- Click file pills in chat to open files.
- Click collapsed tool-call rows to expand tool history.
- Click file-change cards or file rows to inspect diffs.
- Use tabs to switch between AI tasks.
- Use the composer to mention files with @, attach files, link issues, change models, and send prompts.
- Use the right-side changes panel to review modified files.
- Use the embedded terminal to run commands.
- Use the Merge button to merge the ready pull request.

Visual style:
- Dark IDE theme.
- Dense but readable layout.
- Rounded cards and subtle separators.
- Muted gray backgrounds.
- Green for ready-to-merge, additions, and success.
- Red for deletions and conflicts.
- Purple/dark banner for runtime error.
- Monospace font for paths, code, terminal, and file names.
- Small icons throughout, but keep the interface clean.
- The UI should feel like a serious developer tool, not a marketing dashboard.
